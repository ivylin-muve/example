人員職涯與薪酬制度數位化平台

Role: Project Owner / 制度產品化 / 工具開發 Scale: 40+ 專業夥伴使用
核心痛點 (Problem)

舊有制度文字複雜且計算繁瑣，夥伴難以預估投入回報；行政對帳依賴人工溝通，審查與晉升流程不透明。

產品解法 (Solution)

將紙本規範轉化為三大模組：簡報化政策導覽、雙向晉升地圖與動態階梯薪資試算器。

專案成效 (Impact)

大幅降低 80% 制度諮詢成本，建立透明保級與晉升預期，夥伴可自主規劃工作量並即時查看試算成果。

核心設計原則

不加班、不額外加案、回歸「教學品質」與「合約誠信」

專業身份：終身認證資格

只要通過實作考核並獲得 OO 證書，您的「專業身分」將終身有效。 即使因個人規劃暫停接案，您的生涯總經驗堂數將永久保留。

當期報酬：年度動態審查

為了落實品質與對價，「獎勵金級距」採取年度制（每年 1/1 重新起算）。 維持穩定產能（年度 X 堂目標）並配合行政紀律的夥伴，即可享有高階獎勵加成。

經營宗旨：我們不鼓勵暴增課量，而是透過「常態年約門檻」建立穩健永續的服務生態。

不可抗力彈性免除與審查機制

保障老師權益不受個案突發狀況影響，建立人性化配套措施

1. 適用情事定義

  • • 學員不可抗力因素：學員突發重大狀況致使課程中斷。
  • • 案源調度限制：組織因調度限制，未能及時指派新案或補齊減少之課堂數。
  • • 無歸責老師教學違失：老師其餘指派個案正常上課，無可歸責於老師之事由。
★ 因上述情事致當年度實際完課未達年度門檻者適用。

2. 通報與彈性判定

• 主動通報義務：老師須於狀況發生起指定期限內，主動向教學管理部門通報。

• 逾期不予受理：未於期限內通報者，年底盤點時不予採計彈性抗辯。

• 人工彈性審查：經查證屬實者，年底盤點時維持原職級或晉升門檻得依實務狀況折算減免。

解鎖高額獎勵金

降級後回升原職級規定

因降級者之「生涯總累積堂數」已跨越門檻，無需重新累積總堂數。被降級的這一年，夥伴須達成當年度常態任務與目標職級晉升報告，即可於次年正式回升。

行政對帳與預審機制

配合每月固定切帳日與次月發薪之常態流程，實施預審與結算制度

年底大盤點與預審

  • 預審公式： 年度至今實際堂數 + 年底前系統預排課數
  • 提前判定： 兩者相加達標即預先判定通過，保留明年原職等與續約資格。
安全防護機制： 若預審通過後因個人因素無故取消課程致未達門檻，原資格無效並追溯扣回差額。

跨年堂數與獎金拆分

  • 舊年度尾數全變現： 年底最後切帳區間之堂數，不論累積餘數是否滿 N 堂，一律依舊年度費率等比例變現發清。
  • 新年度全新起跑： 新年度首日起的課堂，直接歸入新年度重新累計。
離職回歸與復權管理辦法
1. 中斷服務【短期內】

直接回歸原職級。年底考核目標採剩餘月份比例折算。達標者隔年維持原職級，未達標者隔年調降一級。

2. 離職【中期內】

調降一級落腳發薪。完成當年度任務與報告後，次年正式復權重返原職級。

3. 離職【長期以上】
• 回歸當下職級：回歸初次派案一律由基礎職級起跑。
• 歸隊必備條件：補齊最新必修核心課程並通過考核。
• 年底考核目標：依生涯累積堂數申請晉升至對應職級。
誠信合約與三大防禦紅線

行政延誤採「暫停發放」而非扣款；惡意違約設有懲罰機制

1. 行政配合違失

定期教學報告與檔案需依限繳交。若無故遲交：
• 即時處置 (暫停撥款)：暫停發放該堂課酬，補齊後次月恢復撥款。
• 合約處置 (遲交超過指定期限)：累計達一定次數者，將影響次年續約或調降合作報酬等級。

2. 嚴重違約行為 (利益衝突)

出現下列情事，協會得立即解約並追究損害賠償與違約金：
• 私下使用組織名義收費授課或私用軟硬體設備。
• 無故丟包個案或中途失聯，損害學員權益。

「資格認證是終身的，執業等級是動態的。」

全新師資體系，致力於在不增加夥伴工作負擔的前提下，
透過透明的晉升階梯與合理回饋，一同守護服務品質。
